# Team Roles and Contribution Plan

This file demonstrates how work can be divided among contributors in a shared repository.

| Role | Responsibility |
|---|---|
| Repository Maintainer | Maintains repository settings and protects the main workflow |
| Developer 1 | Creates project files and implements assigned changes |
| Developer 2 | Updates documentation and examples |
| Reviewer | Checks the pull request, readability, and correctness |

## Collaboration Rules
1. Do not commit unfinished work directly to main.
2. Create a separate branch for each task.
3. Use clear commit messages.
4. Keep pull requests focused on one logical change.
5. Review changed files before merging.
6. Update the local main branch after a merge.

## Example Branch Names
- feature/project-setup
- feature/documentation
- fix/readme-typo
